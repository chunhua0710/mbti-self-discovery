## 1. 模組 B：OEJTS 網頁測驗

**作答前，請對方先寫下自評類型**，例如以前測過的結果，或自己猜的類型。官方流程也是先自評，事後才能比對自評、測驗、訪談三者之間的落差。

**測驗資訊**
- **網址**：https://openpsychometrics.org/tests/OJTS/
- **費用與長度**：免費，48 題，約 3–5 分鐘
- **語言**：介面是英文。對方英文不熟時，可以請他把題目貼過來，你逐題翻譯
- **資料**：網站會匿名保存作答資料，可能用於研究。要事先告訴對方
- **性質**：不是官方 MBTI。題目是用「自認知道自己類型的網友」篩選出來的，結果只當作基準

**請對方貼回來的內容**：結果頁上每條軸的兩個分數（每邊 0–36 分），以及網站判定的四個字母。

**對方已有其他結果時**：例如做過正版 MBTI 或 16Personalities，一樣可以拿來當起點，但要說明那份結果是什麼性質（參考 `theory.md` 第 2 節）。

## 2. 讀分數：找出確定和不確定的軸

依每條軸兩邊分數的差距分級。這是**經驗法則**，OEJTS 本身沒有公布切分點：

| 差距 | 判讀 | 訪談策略 |
|---|---|---|
| ≥ 15 | 明確 | 只用一題確認即可 |
| 6–14 | 中等 | 用 1–2 題行為題確認 |
| ≤ 5 | **接近中間，等於不知道** | 列為重點，多用功能題區分 |

把不確定的軸排列組合，列出**候選類型**。

範例：如果 E/I 和 J/P 都不確定，而 N、F 很明確，候選類型就是 INFP、ENFP、INFJ、ENFJ。

再查第 3 節，看這些候選類型的主導功能是否不同。**主導功能不同，就是最有力的區分點。**

## 3. 16 型的功能對照表（依 Myers 的模型）

劣勢功能是主導功能的對立面，態度也相反。

| 類型 | 主導 | 輔助 | 劣勢 | | 類型 | 主導 | 輔助 | 劣勢 |
|---|---|---|---|---|---|---|---|---|
| ISTJ | Si | Te | Ne | | ESTP | Se | Ti | Ni |
| ISFJ | Si | Fe | Ne | | ESFP | Se | Fi | Ni |
| INFJ | Ni | Fe | Se | | ENFP | Ne | Fi | Si |
| INTJ | Ni | Te | Se | | ENTP | Ne | Ti | Si |
| ISTP | Ti | Se | Fe | | ESTJ | Te | Si | Fi |
| ISFP | Fi | Se | Te | | ESFJ | Fe | Si | Ti |
| INFP | Fi | Ne | Te | | ENFJ | Fe | Ni | Ti |
| INTP | Ti | Ne | Fe | | ENTJ | Te | Ni | Fi |

**常見的易混組合**：

| 組合 | 只差哪個字母 | 功能上的差別 |
|---|---|---|
| INFJ / INFP | J/P | Ni-Fe 對 Fi-Ne，兩者沒有共用任何功能 |
| INTJ / INTP | J/P | Ni-Te 對 Ti-Ne |
| ISFJ / ISFP | J/P | Si-Fe 對 Fi-Se |
| ENFP / ENFJ | J/P | Ne-Fi 對 Fe-Ni |

內向型的 J/P 一翻，主導功能就整個換掉，所以這一軸要特別仔細確認。

## 4. 訪談的進行方式

| 輪次 | 內容 |
|---|---|
| 第 1 輪 | 確認自評類型（如果還沒問），加上最不確定那條軸的 1–2 題行為題 |
| 第 2–3 輪 | 用功能區分題分辨候選類型的主導與輔助功能（第 6 節） |
| 第 4 輪 | 用劣勢功能題交叉確認（第 7 節） |
| 追加輪 | 對方說「還不確定」時，針對最弱的那條軸或功能再問 3–4 題 |

**每一輪都要做的事**：
1. 判讀這一輪的回答
2. 更新候選類型
3. 更新紀錄檔，標上確定度
4. 用「支持 A ／ 支持 B」的對照表，呈現目前的證據

## 5. 題庫：四條軸

題目可以改寫成貼近對方生活的說法。每題後面列出常見的干擾因素，判讀時要扣分。

### E / I：能量從哪裡來
- **EI-1**：想一個最近完全沒有安排的週末。你實際上怎麼過？過完之後，是覺得充飽電，還是有點空虛、悶？
- **EI-2**：和一群多半不熟的人相處三小時，結束後你的狀態如何？如果換成很熟的朋友呢？
  - 這題用來區分「怕生」和「內向」：熟人局也會耗電，才比較像 I
- **EI-3**：遇到事情，你比較常先在腦中想清楚再說，還是邊說邊想，說出來才知道自己怎麼想？
- **干擾因素**：害羞、社交焦慮、工作角色，例如業務被要求要外向

### S / N：注意力放在哪裡
- **SN-1**：描述最近看的一部電影，或一趟旅行。你會先講具體發生了什麼、有哪些細節，還是先講感覺、意義、它讓你聯想到什麼？
- **SN-2**：學新東西時，你比較想先拿到步驟和實例，還是先理解原理和全貌？
- **SN-3**：做判斷時，你比較信任過去的實際經驗，還是直覺和預感？
- **干擾因素**：職業訓練，例如會計必須重視細節。可以改問休閒時的情境

### T / F：用什麼做決定
- **TF-1**：做重要決定時，你最後一關會問：「這合不合理、前後一不一致？」還是：「這對相關的人、對我在乎的價值意味著什麼？」
- **TF-2**：朋友拿一個明顯有漏洞的計畫來問你，你的第一反應是先指出漏洞，還是先了解他為什麼想做、先照顧他的心情？
- **TF-3**：被批評時，你最在意的是對方說得對不對，還是對方的態度、以及這件事對關係的影響？
- **干擾因素**：性別社會化、工作要求。另外，統合分析顯示 T–F 是信度最低的一條軸（.61），要特別保守

### J / P：怎麼面對外在世界
- **JP-1**：事情還沒有定案的時候，例如要不要換工作、週末去哪裡：
  - A：懸著很難受，決定了才安心
  - B：保持開放比較自在，太早決定反而像被綁住
- **JP-2**：原本的計畫被臨時改變，你的第一反應是什麼？
- **JP-3**（這題看的是**對外使用的功能**）：初次見面的人，通常怎麼形容你？
  - A1：有條理、果斷、效率高 → 對外是 Te，屬於 J
  - A2：溫和、體貼、很會照顧氣氛 → 對外是 Fe，屬於 J
  - B1：好奇、點子多、話題跳躍、隨性 → 對外是 Ne，屬於 P
  - B2：反應快、活在當下、愛體驗、行動派 → 對外是 Se，屬於 P
  - 內向型的人，外人看到的是他的輔助功能，所以這題對內向型特別有用
- **干擾因素**：拖延受盡責性和焦慮影響，**不能拿來當 P 的證據**；工作規定的計畫性也是干擾。判斷時，偏好（JP-1）比行為更接近 MBTI 想測的東西

## 6. 題庫：功能區分題

只在候選類型的主導或輔助功能不同時才使用。

### Ni / Ne
「你說『想法一直在腦中』，那些想法通常是哪一種？」
- A：往一個方向越想越深，最後收斂成「我知道這件事會怎麼發展」或「它的本質是什麼」→ Ni
- B：一個想法接著冒出好幾個新點子，不停發散、跳來跳去，每個都很有趣，但很難選定一個 → Ne

### Si / Se
「到一個新地方旅行時，你比較像哪一種？」
- A：會拿它和以前熟悉的地方比較，在意自己舒不舒服、習不習慣，記得很多過去的細節 → Si
- B：完全沉浸在眼前的聲音、畫面、氣氛裡，想立刻去體驗、去試，反應很快 → Se

### Ti / Te
「要接受一個說法或做法之前，你需要的是什麼？」
- A：自己真正想通，內部邏輯前後一致，才會安心，就算別人都已經在用了也一樣 → Ti
- B：只要它有效率、能落地、有數據或成果支持，就可以先用，原理之後再說 → Te

### Fi / Fe（建議組合使用，單題的證據力都不強）
- **FF-1**：在一群人當中，你會自動察覺誰不開心、誰被冷落，然後不自覺地出手調整，覺得氣氛不好自己也有責任嗎（Fe）？還是比較會在心裡和個別的人共鳴，不覺得整體氣氛是自己的事（Fi）？
  - 注意：內向的人也可能選後者，要和其他題一起看
- **FF-2**：大家都同意做一件你覺得「有點不對」的事時，你的不舒服來自哪裡？
  - A：「這樣對人不好、不是做人做事該有的樣子」，屬於共同標準 → Fe
  - B：「這不是我，就算大家都覺得沒差，我自己就是過不去」，屬於個人的真實感受 → Fi
- **FF-3**：一段關係裡的不舒服，你一直沒說出口。最大的原因是怕氣氛變差（Fe），還是覺得自己的感受很私密、說不清楚（Fi）？
  - 注意：幾乎每個人描述受傷時，都會用「不被尊重、不符合我在乎的事」這類說法，所以單看用詞的證據力很弱

### 主導功能的「主場」
「完全放鬆、沒有任何人要求你的時候，你最自然會做什麼？那時候你的腦袋在忙什麼？」
主導功能通常就是一個人不需要費力、會自動回去的地方。

## 7. 題庫：壓力下的劣勢功能

以下是根據類型文獻（例如 Naomi Quenk 對劣勢功能的研究）整理的常見描述，個別差異很大。

**提問方式**：只拿兩個候選類型的劣勢描述當作 A、B 選項，**不要告訴對方哪個選項對應哪個類型**。請對方回想長期壓力很大、累到極點時，自己比較像哪一個。

| 劣勢功能 | 對應類型 | 壓力下常見的樣子 |
|---|---|---|
| Se | INFJ、INTJ | 放縱感官（暴飲暴食、狂買、追劇或滑手機停不下來）、做衝動的事、對外在細節特別煩躁或敏感 |
| Ne | ISTJ、ISFJ | 往最壞的可能一路想下去，把事情災難化，對未來感到惶恐 |
| Ni | ESTP、ESFP | 陷入陰暗的內在預感，覺得事情背後有不好的深層意義，變得悲觀 |
| Si | ENFP、ENTP | 過度關注身體的症狀，鑽牛角尖在細節或過去的事情上，退縮起來 |
| Te | INFP、ISFP | 變得挑剔、批評別人沒效率、沒邏輯；突然拼命整理、列清單，想控制一切 |
| Ti | ENFJ、ESFJ | 變得冷硬，尖銳地挑邏輯漏洞，用很冷的方式批判別人 |
| Fe | INTP、ISTP | 情緒失控，對關係變得過度敏感，覺得沒有人在乎自己 |
| Fi | ENTJ、ESTJ | 覺得自己不被賞識，情緒突然爆發，突然很在意別人怎麼看自己 |

**判讀**：壓力下放縱或失控的情形很普遍，所以這一題的作用是「檢查有沒有矛盾」，不能當作決定性的證據。

如果對方的描述剛好吻合，可以引用榮格原典裡相對應的段落，讓對方自己讀讀看。例如內傾直覺型的無意識，被描述為衝動、不受節制的外傾感覺，見原典第十章第 9 節。

## 8. 綜合判讀與最適類型

**證據權重**（由高到低）：

| 權重 | 證據類型 | 例子 |
|---|---|---|
| 高 | 功能層面的題目 | Ni/Ne 收斂或發散、對外功能 |
| 中高 | 偏好層面的題目 | JP-1、EI-1 |
| 中 | OEJTS 差距 ≥ 6 的軸 | |
| 低 | 行為層面、容易受干擾的證據 | 拖延、怕生、單一事件 |
| 低 | 用詞層面的證據 | FF-3 的描述方式 |

**呈現方式**：用一張表列出每個字母、確定程度（高、中、最不確定），以及主要依據，然後提出建議的最適類型。

**最後由對方決定。** 決定之後，在紀錄中寫下：
- 對方的決定和日期
- 依據了哪些資料，例如 OEJTS 加上幾題訪談、有沒有做正版測驗
- 需要保留的部分，例如某條軸接近中間，或帶有其他功能的成分
- 提醒：接近中間的字母只代表「相對的偏好」，一年後可以重測、重新確認

**和自評不一樣時**：先肯定自評本身也是一項證據，再說明是哪些具體回答讓判讀偏向另一邊，請對方自己衡量。
