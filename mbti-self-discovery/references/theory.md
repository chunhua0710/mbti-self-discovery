## 1. 三層理論

網路上的「真假之爭」，多半是把以下三層混在一起講。

### 第一層：榮格《心理類型》（1921 年德文版，1923 年英譯）
| 概念 | 原意 |
|---|---|
| 兩種態度 | 外傾：心理能量流向外在客體；內傾：流向主體內在 |
| 四種功能 | 思考、情感屬於**理性（判斷）功能**；感覺、直覺屬於**非理性（知覺）功能** |
| 八種類型 | 2 種態度 × 4 種功能，例如外傾思考型、內傾直覺型 |
| 主導功能 | 只有一個功能擁有「絕對主權」 |
| 輔助功能 | 一定來自另一條軸。思考主導的人，輔助只能是感覺或直覺，不會是情感（原典第十章第 11 節） |
| 劣勢功能 | 主導功能的對立面，處在無意識中，發展得很原始 |

- 榮格說，純粹的類型只是誇大的「合成肖像」，真實的人都是混合的
- 榮格**沒有提出**：J/P 這條軸、16 型、問卷
- 榮格沒有明確規定輔助功能是內傾還是外傾。後人對這一點的詮釋有分歧

**原典取得**：1923 年 Baynes 的英譯本在美國和台灣都已進入公有領域，archive.org 上有掃描檔，識別碼是 `psychologicaltyp00jung_1`。

### 第二層：Briggs 與 Myers 的 MBTI
- **版本沿革**：1943 Form A → 1962 Form F → 1978 Form G → 1998 Form M → 2001 Form Q → 2018 MBTI Global
- **四條二分軸**：E–I、S–N、T–F，以及她們新增的 J–P
- **J–P 的作用**：看哪一種功能是拿到外在世界使用的，藉此推出主導和輔助功能
- **Myers 的詮釋**：輔助功能的態度和主導功能相反
- **推導例子：INFJ**
  - J 代表外向使用的是判斷功能 F，所以是 Fe
  - I 代表主導功能是內向的，所以主導是 Ni，輔助是 Fe
- **官方立場**：MBTI 測的是偏好，不是能力，也沒有好壞；結果必須由本人確認最適類型

### 第三層：後來加上的說法
**不是榮格原著，也不是官方計分的一部分。**

- **八功能堆疊**（例如 Ni-Te-Fi-Se）：第三、第四個功能的排列是後人的慣例
- **John Beebe 的八功能原型模型**：英雄、父母、兒童、劣勢，以及四個陰影功能。這是 Beebe 提出的臨床理論
- **社會人格學（Socionics）**：另一套獨立的體系，規則和 MBTI 不同
- **官方 MBTI 沒有直接替任何「認知功能」計分**，功能的動力關係都是從四個字母推導出來的

## 2. 哪些測驗不是 MBTI

| 測驗 | 是官方 MBTI 嗎 | 說明 |
|---|---|---|
| 16Personalities | 否 | 它自己表明和 MBTI 不能互換。使用自家的 NERIS 模型，額外加了 A/T 軸（接近 Big Five 的神經質），本質上是特質分數套上 MBTI 字母 |
| 各種免費的「MBTI 測驗」 | 否 | 都是仿作，大多用 Likert 量尺，不是官方的二選一題型 |
| 認知功能測驗 | 否 | 沒有公開的信效度資料 |
| OEJTS（Open Psychometrics） | 否，但方法公開透明 | 以「自認知道自己類型」的網友為效標來挑選題目，所以測到的是「網友眼中每一型的平均樣子」 |
| MBTIonline、認證施測師 | **是** | 付費，包含最適類型確認 |

## 3. 正版測驗長什麼樣子（只描述格式，官方題目有版權）

### Step I：決定四個字母
- **MBTI Global Step I**，共 92 題，各軸題數：E–I 24、S–N 24、T–F 23、J–P 21
- **題型**：二選一的強迫選擇，不是「非常同意到非常不同意」的量尺
- **計分**：用潛在類別分析（LCA），輸出「機率指數」，取代舊版的「偏好清晰度指數」
- 舊版 Form M 共 93 題，用 IRT 計分
- 官方有繁體中文版和簡體中文版

### Step II：每個字母底下的 20 個面向
- 共 143 題，包含 Step I 的 92 題，再加上 51 題
- 每條軸分成 5 個面向，每個面向會判定為「符合偏好」「中間區」或「反向」：

| 軸 | 5 個面向 |
|---|---|
| E–I | Initiating–Receiving、Expressive–Contained、Gregarious–Intimate、Active–Reflective、Enthusiastic–Quiet |
| S–N | Concrete–Abstract、Realistic–Imaginative、Practical–Conceptual、Experiential–Theoretical、Traditional–Original |
| T–F | Logical–Empathetic、Reasonable–Compassionate、Questioning–Accommodating、Critical–Accepting、Tough–Tender |
| J–P | Systematic–Casual、Planful–Open、Early Starting–Pressure-Prompted、Scheduled–Spontaneous、Methodical–Emergent |

- 官方數據：59% 的面向分數落在「符合偏好」，33% 落在中間區，8% 是反向。可見同一型的人，彼此差異其實很大

### 正規的施測流程
1. 由認證施測師施測，或使用 MBTIonline
2. 先學習類型的基本概念，自己先猜一個類型
3. 作答，拿到報告
4. 進行**最適類型確認**。官方把這一步列為倫理要求，最後由本人決定

### 怎麼取得
- **MBTIonline.com**：2026-10 查到的價格是 59.95 美元，約 45 分鐘，包含互動式確認
- **台灣**：我沒有查到可以驗證的授權代理名單和價格。可以向 The Myers-Briggs Company 的亞洲據點詢問，並請施測者出示認證

## 4. 準確度：官方數據和批評其實一致

| 指標 | 數據 | 出處 |
|---|---|---|
| 內部一致性 α | .88–.91 | 官方 Global 增補手冊（美國樣本，N=3,578） |
| 各軸分數重測相關（≤15 週） | .85–.88 | 同上（n=236） |
| 各字母重測一致率 | 82–87% | 同上 |
| **四個字母全部相同** | **51%**；有三個以上相同的是 90% | 同上 |
| 5 週後換了類型的比例 | 最多約 50% | Pittenger 1993 |
| 分數分布 | 不是雙峰，大多數人落在中間附近 | Pittenger 1993 |
| 偏好是類別還是連續的 | taxometric 分析找不到真正的類別 | Arnau 等 2003 |
| 和 Big Five 的關係 | E–I 對應外向性、S–N 對應開放性、T–F 對應親和性、J–P 對應盡責性 | McCrae & Costa 1989；官方 Form M 手冊也有相同方向的相關 |
| 統合分析 | 重測信度：E–I、S–N、J–P ≥ .75；**T–F 只有 .61** | Randall 等 2017 |

**怎麼解讀**：各軸的分數本身很穩定。但大多數人的分數落在中間附近，一旦切成字母，靠近分界的人就容易翻到另一邊。所以四個字母比分數脆弱得多，官方才會要求做最適類型確認。

**其他常見迷思**
- **「INFJ 最稀有」**：官方美國樣本中，INFJ 佔 2.9%，ENTJ（1.8%）和 ENFJ（2.3%）都比它更少
- **中文樣本**：繁體中文的技術報告只有 N=131 的便利樣本；Global 繁中增補手冊的 N=477，來自香港和中國大陸，沒有台灣樣本
- **伴侶「速配類型」**：沒有可靠的研究支持
- **倫理**：結果不能用來標籤、評價或限制任何人；官方也表明，用它來篩選求職者是不道德的

## 5. 依目的選擇的建議
| 目的 | 建議 |
|---|---|
| 想要正版的類型 | MBTIonline 或認證施測師，加上最適類型確認 |
| 有某條軸卡在中間 | 看 Step II 的面向分數，或機率指數 |
| 想要預測力最好的人格描述 | Big Five 或 HEXACO（IPIP 題庫是公有領域） |
| 想忠於榮格的原意 | 讀原典第十章〈General Description of the Types〉。量表可以用 SL-TDI，它用 Likert 量尺分別測 8 個功能態度，不預設兩極 |
