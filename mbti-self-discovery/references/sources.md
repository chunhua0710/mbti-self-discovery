# 出處對照表：每個主張在哪裡查得到

`theory.md` 和其他參考檔裡的主要數字與說法，都可以在這裡找到出處和頁碼；少數沒有單一出處的說法，會直接註明。對方問「這個數字哪裡來的」時，直接引用這份表。

**頁碼怎麼看**
- 官方文件和論文：寫的是 **PDF 檔的頁序**（在 PDF 閱讀器輸入頁數就能跳到），不是文件上印的頁碼
- 榮格原典：寫的是**原書印刷頁碼**，和 `jung-1923/` 裡的〔p. N〕標記一致

**權利說明**
- 有版權的文件（官方技術文件、期刊論文）只附連結，不收錄檔案
- 榮格原典第十、十一章是公有領域，全文收在 `jung-1923/`
- 每個連結盡量附上 Wayback Machine 的備份，原網址失效時可以用

## 目錄
1. 主張 → 出處 → 頁碼
2. 文獻清單（連結、備份、DOI、書籍）
