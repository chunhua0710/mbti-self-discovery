# 模組 F：情感需求訪談

**目的**：透過關係史訪談，以及對方主動提供的關係資料（選做），整理出三件事：
- 對方在親密關係裡的核心需求
- 這些需求從哪裡來
- 需求在「說出口」和「被聽到」之間落差在哪裡

**這個模組不做任何量表。** 分析時只描述**行為模式**，例如「不安時會追問，沒得到回應就退開」。不要替對方貼上「焦慮型」「逃避型」這類依戀類型的標籤，因為標籤需要經過驗證的量表才能下。對方自己提到某個標籤時，說明這只是一種詮釋，還沒有經過測量。

**和 MBTI 的分工**：
- MBTI 說的是一個人的**偏好**，例如需要意義、需要獨處充電
- 情感模式說的是**親密關係受到威脅時的反應**
- 兩者不同層次，不要用類型來解釋感情衝突，例如「因為你是 INFJ 所以會這樣」

## 1. 關係史訪談

一次問 2–4 題。開始前先說：「不想回答的可以跳過。」

- **H1**：在過去的關係裡，你覺得最被愛的一刻是什麼？最不被愛的一刻呢？
- **H2**：吵架時，你第一個反應通常是什麼？接著會做什麼？如果吵到很嚴重，你會說什麼、做什麼？
  - 這題是要還原**完整的循環**，不是只問第一步
- **H3**：對方怎麼回應，最能讓你安心？怎麼回應最讓你受不了？
- **H4**：吵完之後，通常是誰先走回來？用什麼方式？
- **H5**：小時候，當你需要大人的時候，通常得到什麼樣的回應？
  - 這題比較敏感，一定要告訴對方可以跳過
- **H6**：心裡有感受說不出口的時候，你通常怎麼處理？只找一個特定的人說，還是有好幾個出口？

如果已經做過模組 D，可以直接引用 F1–F3（家庭）和 C2（抒發方式）的回答，不必重問。

## 2. （選做）閱讀對方提供的關係資料

**只有在對方主動提出、並明確同意時才做。** 例如對方說：「你可以讀我存下來的聊天紀錄。」

**找資料的範圍**：
- 只讀對方指定的資料夾
- 找不到時，問對方確切的位置，或只在對方的家目錄裡用名稱搜尋。不要大範圍翻找

**讀的順序**（這類資料通常很大，可能有上萬行的聊天紀錄）：
1. 先讀對方之前做過的分析或摘要，例如覆盤筆記、簡報、按月份整理的敘事
2. 再挑出和**對方本人**有關的段落
3. 最後用原始紀錄**抽查**關鍵引句是否真的存在。用 `grep -c` 之類的指令計次，不要逐行讀完全部紀錄

**界線**：
- 分析焦點放在**對方本人**的需求和模式。不替第三方做人格判斷，也不評斷第三方
- 引用第三方的話時，只取必要的部分；紀錄中用「前任」或「對方」稱呼，不寫第三方的真實姓名
- 要註明：之前的分析和敘事是**詮釋**，不是逐字紀錄
- **不要把這些內容放進任何要分享給別人的檔案**

**最有價值的發現**：通常是**本人的自我描述和紀錄之間的落差**。

常見的落差：
- 自認「很少主動聯絡」，紀錄裡卻是一天傳幾十則訊息
- 自認「都是對方先生氣」，紀錄裡卻每次都是自己先冷下來
- 自認「我都忍著不說」，紀錄裡卻是忍到某個點以後一次全部爆發

**指出落差時**：
1. 把完整的循環說出來，不要只講其中一段
2. 不責怪
3. 找出對方在紀錄裡已經做到的進步，並具體指出時間點和做法。例如某一次願意先開口，或某一次沒有翻舊帳

## 3. 綜合分析的架構

| 段落 | 內容 |
|---|---|
| 0. 落差 | 自我描述和紀錄不一致的地方（有才寫） |
| 1. 核心需求 | 4–6 項。用表格列出：需求、在關係裡的樣子、證據 |
| 2. 需求的來源 | 依時間排列：童年 → 青少年 → 家庭 → 職涯 → 感情，寫出每個時期學到的信念。只寫對方說過的話，或紀錄裡確實有的內容，不要自行編造 |
| 3. 表達的落差 | 對照表：真正的感受、實際說出口的話、對方聽到的意思 |
| 4. 已經做到的事 | 具體的進步時刻 |
| 5. 下一段關係的指南 | 適合的伴侶特質（看行為，不看類型），以及自己要帶進去的改變 |
| 6. 和 MBTI 的關係 | 兩者怎麼分工 |

**常見而且有用的觀察**（實際符合時才用）：
- **兩個人要的是同一樣東西，給的方式卻剛好是對方最受不了的。** 例如兩人都想「被看見、被接住」，一方用追問和講道理去要，另一方用冷處理保護自己
- **需求底下常常還有一層更深的恐懼。** 例如「想被看見」底下是「怕被丟下」
- **跨模組的連結**：模組 D、E 已經發現的核心需求，例如「被看見」，常常也會在感情裡出現。把這條線串起來，往往是最有力量的洞察
- **說出需求的句型**：「我覺得＿＿，因為＿＿，我需要你＿＿。」
- **離開時說清楚會回來**：「我需要一小時冷靜，但我會回來。」不要封鎖，也不要直接消失
- **不要記帳**：付出是自己的選擇，不是對方欠下的債
- **把確定感的來源分散開**，不要只依賴一個人

**專業協助**：這些模式常常是從童年一路累積下來的。可以建議對方找專做伴侶關係或情緒取向治療（EFT）的諮商師。說法要是「有人陪著走會快很多」，不要讓對方聽成「你有問題」。
